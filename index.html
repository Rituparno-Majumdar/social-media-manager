⚠️ Getting 503 Errors repeatedly?

1. Network Firewall / Proxy: Office, school, or corporate firewalls often block direct browser calls to Google API endpoints (`generativelanguage.googleapis.com`) and return a 503 error. Try switching to a mobile hotspot or home Wi-Fi.

2. Ad Blocker / Extensions: Aggressive privacy extensions can intercept and block API requests. Try running the app in an Incognito Window or temporarily pause ad blockers.

3. Regional / VPN Block: If using a VPN, Google's rate-limiter may flag the IP. Try turning off your VPN or setting the location to India, US, or Singapore where the Gemini API is fully operational.
